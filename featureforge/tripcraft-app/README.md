# tripcraft-app

This directory is intentionally empty (aside from this file).

It's the **output** of FeatureForge, not something we hand-write. Every file
that eventually appears here — the Express backend, the React frontend, the
database schema — will be created by describing a feature to FeatureForge
(`POST /api/features/plan`, review the diff, then `POST /api/features/apply`)
and letting it build the app.
